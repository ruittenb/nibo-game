# Design: S6 & S7 — New Stages

## Context
With positions 19-24 infrastructure in place, we need to design the content for the two new stages. This document captures the creative direction and game design decisions — it's a design reference, not an implementation plan for a single PR.

## Overview

```
S0 - S2 (jungle) - S3 (hangar)    - S6 (rear spaceship)
S1 (factory)     - S4 (caves)     - S5 (sunken city)  - S7 (temple)
```

**New winning route extension:** After reaching S3's cockpit, the player discovers the engines are broken. They need an engine part from S6, but S6 is radioactive. The radiation shield is in S7's temple, which demands loot as tribute. This makes collected loot essential for progression.

**Flow:** Existing stages → S3 cockpit (engines broken) → S7 temple via S5 (pay loot, solve puzzles, get radiation shield) → S6 rear spaceship (survive radiation, retrieve engine part) → S3 cockpit (install part, escape)

## S6: Rear of the Spaceship (top, L5-L9, pos 19-24)

**Theme:** The back half of the crashed spaceship — exposed engine bay, damaged hull, warning signs. Radioactive contamination from the cracked reactor.

**Access:** From S3 (pos 18→19 at upper levels). Requires radiation shield from S7.

**Goal:** Retrieve the engine part needed to repair the ship and escape.

**Key mechanics:**
- **Per-position radioactivity** — specific positions on the required path are radioactive death zones. Without the radiation shield, stepping on them triggers a death screen. With the shield, the player passes safely. Visually marked with a localized green/toxic glow per hazardous position.
- **Engine part pickup** — new item checkbox, flies to inventory
- Navigation is straightforward once you have the shield — the challenge was *getting* the shield in S7

**New items:**
- `radiation-shield` (picked up in S7, required to survive S6's radioactive positions)
- `engine-part` (picked up in S6, used at S3 cockpit to complete escape)

**Visual style:** Metallic spaceship interior, exposed wiring, cracked reactor with green glow, warning stripes. Radioactive positions marked with hazard symbols and green particle effects.

## S7: Ancient Alien Temple (bottom, L0-L4, pos 19-24)

**Theme:** Mayan/Incan-inspired alien temple — stepped pyramidal architecture, geometric stone carvings with alien glyphs, overgrown with strange vegetation. Atmospheric and mysterious. Contains the radiation shield as its central treasure.

**Access:** From S5 only (pos 18→19 at lower levels). One entrance. No shortcut exit — player must retrace through the temple to return (crumbling bridges make the return path different from entry).

**Goal:** Navigate the temple, pay tribute to guardians, solve puzzles, claim the radiation shield.

**Key mechanics:**

### 1. Guardian Statues (loot gates)
Multiple stone guardian NPCs positioned at chokepoints throughout the temple. Each demands a portion of collected loot before allowing passage.

- **Implementation:** CSS checks if N loot checkboxes are `:checked`. Arrow/passage only shown when threshold met.
- **~75% of total loot required** across all guardians combined, so players can miss a few items but not many.
- **Visual:** Stone statues with glowing eyes. Passage blocked by stone door that opens when tribute paid.
- Could have 2-3 guardians, each requiring a subset of loot items.

### 2. Crumbling Bridges
One-way platforms that disappear after crossing — forcing commitment to a path.

- **Implementation:** Checkbox triggered on arrival at destination. When checked, the bridge platform + return arrow are hidden. CSS: `#bridge-1-crossed:checked ~ .game-world .bridge-1 { display: none; }`
- **Design tension:** Cross the wrong bridge and you're stuck on a longer route (or dead end requiring backtrack through another path).
- Forces the player to observe and plan before moving.

### 3. Pressure Plates
Stepping on certain positions opens passages elsewhere while closing others. Creates routing puzzles.

- **Implementation:** Position-based — when player is at a specific pos+level, certain arrows/platforms become visible while others hide. Pure CSS with `#pos-X:checked ~ #level-Y:checked` selectors.
- **Key difference from bridges:** Reversible. Move off the plate and passages reset. Player needs to figure out the right sequence.
- Could combine with crumbling bridges: activate a plate to open a path, then cross a crumbling bridge before the plate resets.

### Temple Layout Sketch
```
L4: [entrance from S5] → first guardian (loot gate) → main hall
L3: main hall → pressure plate puzzle → crumbling bridge choice
L2: deeper chambers → second guardian (more loot) → trapped corridor
L1: inner sanctum → final puzzle
L0: shrine — radiation shield reward → exit path back up
```

## New Items Summary

| Item | Location | Purpose | Consumed? |
|------|----------|---------|-----------|
| Radiation shield | S7 temple (inner sanctum) | Survive S6 radioactivity | No (worn) |
| Engine part | S6 engine bay | Install at S3 cockpit to escape | Yes |

## New Checkboxes

- `radiation-shield-pickup` — picked up in S7
- `engine-part-pickup` — picked up in S6
- `bridge-N-crossed` — one per crumbling bridge (2-3 expected)
- `guardian-N-paid` — one per guardian statue (2-3 expected)
- Modified escape condition: requires `engine-part-pickup` + existing `flight-controls-used`

## Resolved Decisions

- **Radioactivity:** Per-position death zones on the required path (not full overlay)
- **Temple aesthetic:** Mayan/Incan alien — stepped stone, geometric glyphs, alien twist
- **Backtracking:** No shortcut. Player retraces through temple (different route due to crumbled bridges)

## Open Questions

- **S3 cockpit rework:** Currently the cockpit triggers escape directly. Needs to be split into "discover engines broken" + later "install engine part and escape". How exactly?
- **Pressure plate specifics:** How many plates, what do they control? Need a concrete puzzle layout.
- **Crumbling bridge layout:** How many bridges, which ones create meaningful route choices vs dead ends?
- **Guardian loot distribution:** Which specific loot items does each guardian require? (Total ~75% of all loot)
